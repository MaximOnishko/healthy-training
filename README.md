# Фитик 🌱 — сайт про питание, похудение и тренировки

Статический сайт (HTML + CSS + JS). Сервер и база данных не нужны: данные пользователя
хранятся в его браузере (`localStorage`), «личная ссылка» кодирует профиль в адресе.

## Структура

```
HealthyTraining/
├── index.html        # Старт: заставка с музыкой, Фитик, анкета (рост/вес/цель)
├── diary.html        # Личная страница: норма калорий, БЖУ, рацион, вода, вес, график
├── workouts.html     # Программы, библиотека упражнений, калькулятор расхода калорий
├── timer.html        # Интервальный таймер (HIIT / табата)
├── nutrition.html    # Советы по питанию
├── shops.html        # Ссылки на магазины
├── game.html         # Мини-игра «Накорми Фитика»
├── css/style.css     # Весь дизайн
├── js/
│   ├── data.js       # ★ Питание: блюда, магазины, советы, фразы Фитика
│   ├── sport.js      # ★ Спорт: программы, упражнения, недельные планы, MET
│   ├── calc.js       # Формула Миффлина — Сан Жеора, БЖУ, подбор рациона
│   ├── storage.js    # localStorage + личная ссылка
│   ├── audio.js      # Музыка/звуки (синтез, без mp3)
│   ├── mascot.js     # Робот Фитик (SVG, настроения)
│   ├── layout.js     # Шапка и подвал
│   ├── onboarding.js # Заставка и анкета
│   ├── diary.js      # Логика дневника
│   ├── pages.js      # Рендер тренировок/питания/магазинов
│   └── game.js       # Игра
└── assets/favicon.svg
```

## Запуск локально

Просто откройте `index.html` в браузере. Или:

```bash
npx serve .
```

## Хостинг (бесплатно)

- **GitHub Pages:** загрузите папку в репозиторий → Settings → Pages → Branch `main` / root.
- **Netlify / Cloudflare Pages / Vercel:** перетащите папку проекта в панель (build-команда не нужна, publish directory — корень).
- Любой обычный хостинг: загрузите все файлы в `public_html` по FTP.

## Что менять в первую очередь

1. `js/data.js` → `shops`: замените `example.com` на реальные/партнёрские ссылки.
2. `js/data.js` → `meals`, `workouts`, `tips`: свой контент.
3. Фото и картинки: положите в `assets/` и подключите в HTML/CSS.
4. Название и тексты — в `index.html` и `js/layout.js`.
